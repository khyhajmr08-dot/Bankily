# بنكيلي — محاكاة تفاعلية

مشروع تجريبي يحاكي واجهات وتدفق تحويل الأموال وفق الصور المرجعية المرفقة. لا ينفذ تحويلات مالية حقيقية ولا يتصل بمؤسسة مالية.

## تشغيل نسخة الويب
```bash
npm install
npm run dev
```
لبناء نسخة النشر: `npm run build`، ومجلد الناتج هو `dist/`.

## التثبيت كتطبيق
المشروع مجهز كتطبيق ويب تقدمي PWA. بعد نشره على رابط HTTPS افتح الرابط في Chrome على Android ثم اختر تثبيت التطبيق أو إضافته إلى الشاشة الرئيسية. يجب أن يعمل بعد التثبيت في نافذة مستقلة وفق دعم المتصفح.

## نسخة Android
يوجد مشروع Kotlin/Jetpack Compose داخل `android/`. يمكن بناء APK تجريبي من تبويب Actions عبر سير العمل Build Android APK. لم يتم اعتماد APK على أنه مختبر على جهاز فعلي.

## تنبيه
هذه محاكاة تعليمية فقط وليست خدمة مصرفية ولا تنفذ تحويلات حقيقية.
